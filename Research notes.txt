portal stuff:
	on map load:
		- pn: portal name, basically what kind of portal is this
			- out00: comes out this end
			- in00: comes in this end

			- sp: start point
			- pi - portal invisible
			- pv - portal visible
			- pc - collision
			- pg - changeable
			- tp - town portal
			- ps - script
			- pgi - changeable invisible
			- psi - script invisible
			- pcs - script collision
			- ph - hidden
			- psh - script hidden
			- pcj - collision vertical jump
			- pci - collision custom impulse
			- pcig - look we dont know what the fuck this one does ok

		- pt: portal type. It's more specific
			- 0: Start point
			- 1: Invisible
			- 2: Visible
			- 3: Collision
			- 4: Changeable
			- 5: Changeable invisible
			- 6: TownPortal point
			- 7: Script
			- 8: Script invisible
			- 9: Collision script
			- 10: Hidden
		- x, y: self-explanatory
		- tm: Target map
